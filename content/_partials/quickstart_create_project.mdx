## 1. Create a Zuvo project

To start, you need a Zuvo project.

Create a new Zuvo project from [the Dashboard of any organization](/dashboard/new/_) you belong to.

<Admonition type="note" title="Want to create a project programmatically?">

Use [the Management API](/reference/api/v1-create-a-project) or ask [the MCP server](/guides/ai-tools/mcp#account-management) to create a new Zuvo project.

</Admonition>
