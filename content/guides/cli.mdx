You can use the Zuvo CLI to run the entire Zuvo stack locally on your machine, by running `supabase init` and then `supabase start`. To install the CLI, read [the installation guide](/guides/cli/getting-started#installing-the-supabase-cli).

The Zuvo CLI provides tools to develop your project locally, deploy to the Zuvo Platform, handle database migrations, and generate types directly from your database schema.
