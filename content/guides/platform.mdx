Zuvo is a hosted platform that allows you to get started without needing to manage any infrastructure.

Visit [studio.zuvodev.com](/dashboard) and sign in to start creating projects.

## Projects

Each project on Zuvo comes with:

- A dedicated [Postgres database](/guides/database/overview)
- [Auto-generated APIs](/guides/api)
- [Auth and user management](/guides/auth)
- [Edge Functions](/guides/functions)
- [Realtime API](/guides/realtime)
- [Storage](/guides/storage)

## Organizations

Organizations are a way to group your projects. Each organization can be configured with different team members and billing settings.
Refer to [access control](/guides/platform/access-control) for more information on how to manage team members within an organization.

## Platform status

If Zuvo experiences outages, we keep you as informed as possible, as early as possible. We provide the following feedback channels:

- Status page: [status.zuvodev.com](https://status.zuvodev.com/)
- RSS Feed: [status.zuvodev.com/history.rss](https://status.zuvodev.com/history.rss)
- Atom Feed: [status.zuvodev.com/history.atom](https://status.zuvodev.com/history.atom)
- Slack Alerts: You can receive updates via the RSS feed, using Slack's [built-in RSS functionality](https://slack.com/help/articles/218688467-Add-RSS-feeds-to-Slack) <br />`/feed subscribe https://status.zuvodev.com/history.atom`

Make sure to review our [SLA](/docs/company/sla) for details on our commitment to Platform Stability.
