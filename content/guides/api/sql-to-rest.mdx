Sometimes it's challenging to translate SQL queries to the equivalent [PostgREST](https://postgrest.org/) request or Zuvo client code. Use this tool to help with this translation.

<Admonition type="note">

PostgREST supports a subset of SQL, so not all SQL queries will translate.

</Admonition>
